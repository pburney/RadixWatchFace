Radix

A Wear OS watch face that counts in whatever base you pick — right now, every base from binary (base 2) through nonary (base 9): binary, trinary, quaternary, quinary, senary, septenary, octal, and nonary. This is a live preview: pick a base, a color scheme, a theme, and watch it read the actual time.

Open source (Apache-2.0) — view the source on GitHub. Radix consolidates the Binary and Quinary watch faces into one app with a base/color picker. Built with Claude Code.
