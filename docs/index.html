Privacy Policy — Radix Watch Face

Last updated: September 25, 2026

Radix is a Wear OS watch face built entirely with Android's Watch Face Format — a declarative XML format with no application code. There is nothing in this app that could collect, store, or transmit data even if it wanted to.

What this app does

  • Displays the current time in whichever numeral base you pick (base 2 through base 9), read from the watch's own clock.
  • Optionally displays heart rate, weather, and date complications — standard Wear OS widgets. The data for these comes from whatever complication provider you choose in the watch face editor (e.g. your phone's own health or weather app); this watch face only asks the operating system to render whatever that provider supplies. It never receives, stores, or forwards that data itself.

What this app does not do

  • It requests no Android permissions — check the app's own AndroidManifest.xml in the public source repository.
  • It has no network access, no analytics, no advertising, no accounts, and no in-app purchases.
  • It does not collect, store, transmit, or share any personal data, on the device or off it.

Source

This app is open source (Apache-2.0) — the entire watch face family is generated from one Python script, and the generated watchface.xml is the entire app. See github.com/pburney/RadixWatchFace.
